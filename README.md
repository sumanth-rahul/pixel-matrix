# Image Processing Toolkit

A Python-based image processing toolkit that implements
different image processing techniques using NumPy,
OpenCV, and matrix operations.

## Features

- Image compression using SVD
- Black and white image conversion
- Image blurring
- Image sharpening
- Edge detection
